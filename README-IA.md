# Uso de Inteligência Artificial no Projeto Loomi

Este projeto foi desenvolvido com o apoio de ferramentas de Inteligência Artificial (IA), que aceleraram e aprimoraram diversas etapas do desenvolvimento. A IA foi utilizada para:

- **Ajustes de validações de formulários**: Sugestão de regras, integração com Zod, feedback visual e UX.
- **Construção de formulários**: Estruturação de campos, lógica de estados, acessibilidade e responsividade.
- **Sugestões de refatorações**: Melhoria de legibilidade, modularização, extração de funções e componentes.
- **Construção de componentes reutilizáveis**: Cards, badges, modais, tabelas, gráficos e layouts flexíveis.
- **Dicas de uso do Tailwind CSS**: Classes utilitárias, responsividade, design system, animações e boas práticas.
- **Dicas de uso do Next.js**: Estrutura de rotas, middleware, otimização de performance, SSR/SSG, App Router.

## Exemplos de Prompts Utilizados

Abaixo estão exemplos reais de prompts que foram utilizados para obter sugestões e acelerar o desenvolvimento com IA:

### 1. Validação de Formulários

```
"Crie um schema Zod para validar email e senha, com feedback visual em tempo real."
"Como implementar validação de senha forte usando Zod e mostrar erros no input?"
```

### 2. Construção de Formulários

```
"Monte um formulário de login com toggle para mostrar/ocultar senha e checkbox 'lembrar-me'."
```

### 3. Refatoração de Código

```
"Sugira uma refatoração para separar lógica de filtros em um componente de tabela."
"Como extrair funções utilitárias para formatação de datas e status?"
```

### 4. Componentes Reutilizáveis

```
"Construa um componente Badge para status e prioridade, com variantes de cor."
"Crie um Card de resumo de tickets, responsivo e reutilizável."
"Como criar um modal que fecha ao clicar fora e suporta modo de edição?"
```

### 5. Tailwind CSS

```
"Quais classes usar para responsividade em grid e flex no Tailwind?"
"Como aplicar animações de entrada e hover em botões com Tailwind?"
"Sugira um design system de cores para o projeto usando Tailwind."
```

### 6. Next.js

```
"Como proteger rotas com middleware no Next.js App Router?"
"Sugira estrutura de pastas para um projeto Next.js com Redux e Tailwind."
"Como otimizar carregamento de páginas e usar SSR/SSG no Next.js?"
```

### 7. Documentação

```
"Construa documentação da organização do projeto"
"Construa a documentação de boas praticas de commits"
```
